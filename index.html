1. Semantic HTML

Semantic tags such as header, nav, main, article, section and footer describe the meaning of content. Search engines and screen readers depend on them.

2. Styling with CSS

CSS controls colours, spacing and layout. Good contrast and readable font sizes make a page easier for everyone to use.

3. Interactivity with JavaScript

JavaScript adds behaviour to a page, such as menus, forms and live content, without reloading the page.

Quick SEO Tips

  • Use one h1 per page
  • Write a clear title and meta description
  • Add alt text to every image
  • Keep headings in order (h1, h2, h3)
